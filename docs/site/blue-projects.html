Blue Projects AI skill

blue-projects teaches a coding agent how to work with Blue's .blue composition files without opening the desktop app. It includes a walkthrough and a sample project.

Install the skill

Use Node.js 22.20 or later and run the following command from your project folder.

npx skills add kunstmusik/blue --skill blue-projects

Choose your coding agent when prompted. Add -g to install the skill for use across projects. See the skills installer documentation for supported agents and installation options.

What you can ask your agent to do

  • Inspect a project's instruments, score layers, and load diagnostics.
  • Make a targeted edit, save a separate copy, and reload it to verify the change.
  • Compile a trusted project to a Csound .csd file for disk rendering, realtime playback, or Blue Live.

For example, ask “Use the blue-projects skill to inspect project.blue and summarize its instruments and any load warnings.”

The skill uses Blue Data for inspection and editing and the Blue CLI for compilation. Compilation can run embedded scripts and shell commands. Use inspection first for unfamiliar projects.
