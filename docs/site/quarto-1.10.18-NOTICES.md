# Quarto 1.10.18 manual asset notices

This notice accompanies the Blue 3 manual rendered with Quarto 1.10.18. It covers the generated theme and JavaScript assets under the edition's site_libs directory. Keep it beside the manual edition and link to it from that edition's license/about area. It supplements the manual's GFDL 1.3 text in COPYING.GFDL; it does not change the manual text or screenshot license.

## Build and source pin

The local render used Quarto 1.10.18 from the macOS release archive. The archive SHA-256 is `ddd6a71a9e0448ab15fb655bc589e11cb6589a248ec35ccd7f7f44137531688e`, matching the `quarto-1.10.18-macos.tar.gz` entry in the release's checksums.txt. The exact renderer source is [Quarto v1.10.18](https://github.com/quarto-dev/quarto-cli/tree/v1.10.18).

For assets copied from Quarto's share tree, the emitted files were byte-compared with that exact release. The theme CSS files are generated by Quarto from its bundled Bootstrap Sass and built-in Cosmo/Darkly theme sources, so their provenance is traced to those inputs instead. The hashes below are SHA-256 values of files emitted into the manual output. For vendor assets, release comments and Quarto's source history identify the upstream component version.

Quarto's bundled theme sources descend from the Bootswatch theme import in [Quarto commit e7bdd64](https://github.com/quarto-dev/quarto-cli/commit/e7bdd64c6379bafb6dba9cd812e6466c92655610) on 2021-05-18, after [Bootswatch v5.0.1](https://github.com/thomaspark/bootswatch/tree/v5.0.1) was released. Quarto later modified those built-in SCSS files. The current, exact code source is the Quarto v1.10.18 tag; the Bootswatch MIT notice and copyright are retained below.

The pinned manual's offline font stylesheet sets the Bootswatch web-font URL to false. The rendered CSS does not request Google Fonts. No extra font file is emitted by this Quarto render; the only emitted font is Bootstrap Icons.
