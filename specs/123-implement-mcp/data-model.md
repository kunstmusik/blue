# Data Model — Local MCP access for Blue

| Entity | Owner and lifetime | Fields and invariants |
| --- | --- | --- |
| Preferences | Program Settings, persisted in app user data | `enabled` defaults to false, `preferredPort` is an integer from 1024 through 65535 (default 8765), and `accessMode` is `read-only` by default or `read-write` after an explicit selection. Missing historical settings receive defaults. Invalid persisted enablement or mode fails closed. |
| Credential | Electron main, persisted as protected ciphertext where available | 32 random bytes represented by 64 lowercase hexadecimal characters. A memory-only token is usable for the current run if no secure provider is available. A temporarily locked existing credential leaves the endpoint unavailable until retry or explicit recovery. Rotation revokes old requests and streams before provisioning the replacement. |
| Service status | MCP service, projected to Settings | `stopped`, `starting`, `restarting`, `listening`, or `error`. Only `listening` carries the active port and optional fallback source. `error` carries a sanitized diagnostic. Status always excludes the credential. |
| Subscription stream | MCP service, disposable | SDK stream handle, listener generation, credential epoch, cancellation signal, and subscribed resource URIs. Ordinary calls are stateless. Close drops subscriptions, timers, and outstanding stream references. |
| Authorization context | MCP service and bridge, spans one request | Captures the listener and credential epochs, granted action, abort signal, and required document receipt. Gates run at admission and again before side effects after each asynchronous boundary. |
| Document receipt | ProjectSession and ProjectHistory | `documentId`, `revision`, `stateId`. Undo/redo can revisit a history state while revision continues to increase. The three values must match together. A detached generation input or read projection carries the receipt that produced it. |
| Score locator | Derived from the versioned score projection | Zero-based layer-group path and layer/object index within one document revision. Ordinary project identity remains canonical; a locator ceases to be usable after any receipt change. |
| Commit outcome | ProjectHistory and runtime reconciliation | Current receipt, changed flag, and applicable reconciler outcomes. A rejected operation creates no history entry. A no-op returns the current receipt. A committed edit returns success with a separate diagnostic when runtime reconciliation reports a warning. |
| Engine observation | Existing runtime owner; MCP retains a bounded console tail | Connection and playback state, active document identity where known, and bounded recent Csound output. Clear the tail at project replacement or engine reset. An unavailable engine is a reported state. |
| Render authorization and result | Main runtime and filesystem; disposable | Version-bound request, locally resolved native root, leaf filename, temporary output owner, and terminal success, rejection, cancellation, or failure. Success identifies the final output. Pending artifacts are removed on failure or cancellation. |

Project notifications and service settings events are projections of their owners. No MCP entity enters project XML, instrument libraries, or history payloads. See [lifecycle transitions](plan.md#lifecycle-and-effect-ownership) and the [wire contract](contracts/local-mcp.md).
